#  Лабораторная работа №1: Основы 3D-графики (Vulkan)

**Автор:** Тоймухаметов Радмир

Реализация первой лабораторной работы по дисциплине «Компьютерная графика» на базе низкоуровневого графического API **Vulkan**.

---

##  Вариант и задание

* **Вариант:** №8 — **Цилиндр** (~50 вершин в основаниях)
* **Целевая оценка:** 4 (базовое задание + первые 5 дополнительных заданий)
* **Стек технологий:** C++20, Vulkan API, GLFW, ImGui, GLM, CMake

---

##  Реализованный функционал

### Базовое задание

* **Построение 3D-сетки цилиндра:** алгоритмическая генерация N = 50 секторов оснований и боковой поверхности.
* **Индексация вершин:** использование index buffer для эффективного построения треугольных вееров оснований и полигонов боковой поверхности.

### Дополнительные задания (1–5)

1. **Переключение проекций (Доп. 1):** интерактивный переключатель между перспективной (`glm::perspective`) и ортографической (`glm::ortho`) матрицами проекции.
2. **Интерактивные трансформации (Доп. 2):** полный контроль позиции (translate), поворота (rotate по осям X, Y, Z) и масштаба (scale) объекта через элементы управления ImGui.
3. **Анимация по сложной траектории (Доп. 3):** движение объекта по пространственной эллиптической спирали с возможностью паузы/воспроизведения, настройкой скорости движения, радиуса орбиты и амплитуды высоты.
4. **Управление цветом (Доп. 4):** элемент управления `ImGui::ColorEdit4` для динамического изменения цвета фигуры.
5. **Процедурная окраска вершин (Доп. 5):** автоматический градиентный цвет вершин в зависимости от их локальных XYZ-координат. Цвет вершины покомпонентно умножается на выбранный в ImGui цвет в вершинном шейдере.

##  Зависимости и требования

Для сборки и запуска проекта понадобятся:

* Компилятор C++20 (MSVC 2019/2022, GCC 10+, Clang 10+)
* **Vulkan SDK** (включая компилятор шейдеров `glslc`)
* **CMake** версии 3.20 или выше

Все сторонние C++ библиотеки (**GLFW**, **vk-bootstrap**, **VMA**, **ImGui**, **GLM**) автоматически загружаются при сборке через `FetchContent` в CMake.

##  Сборка и запуск

### 1. Клонирование репозитория

```bash
git clone --depth 1 https://github.com/vladeemerr/vulkan-starter-app
cd vulkan-starter-app
```

### 2. Сборка через CMake (Windows / MSVC)

Все команды выполняются **из Developer Command Prompt for VS 2022/2026**, иначе линкер подхватит x86-библиотеки и сборка упадёт с ошибкой `LNK2001 mainCRTStartup`.

```bash
# Конфигурация проекта
cmake -S . -B build-debug

# Сборка проекта и компиляция шейдеров
cmake --build build-debug --parallel
```

### 3. Запуск

Запускать **из корня проекта**, иначе программа не найдёт `shaders/shader.vert.spv` по относительному пути.

```bash
build-debug\Debug\vulkan-starter-app.exe
```

### 4. Компиляция шейдеров (автоматически)

При сборке CMake автоматически компилирует шейдеры из папки `shaders/` с помощью `glslc`:

* `shaders/shader.vert` → `shaders/shader.vert.spv`
* `shaders/shader.frag` → `shaders/shader.frag.spv`

##  Управление

Всё управление выполняется через ImGui-панель в левом верхнем углу окна:

| Секция | Что делает |
|--------|-----------|
| **1. Camera & Projection** | Переключение перспективная/ортографическая, слайдер FOV или Ortho Size |
| **2. Manual Transform** | Позиция, поворот, масштаб цилиндра |
| **3. Animation** | Пауза/воспроизведение, скорость, радиус орбиты, амплитуда по Y |
| **4 & 5. Object Color** | Выбор цвета — умножается на процедурный цвет вершин |
